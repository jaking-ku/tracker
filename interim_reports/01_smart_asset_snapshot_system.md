# 중간 보고서 01: 스마트 총자산 스냅샷 기반 자산 단일화 및 모바일 핀테크 시스템

## 1. 개요 및 배경
* 기존 시스템: '초기 자산'이라는 기준값에 건별 저축/지출을 가감하던 과거 복잡한 모델을 탈피
* 핵심 개선:
  * **초기 자산 입력 제거 및 현재 자산 단일화**: 특정 시점의 통장 잔액을 직접 입력하면 그 자체가 현재 자산이 되는 직관적인 스냅샷 모델로 완전 통합
  * 상단 대시보드에 **자원 현재 자산**, **예인 현재 자산**, **합산 총자산**만 명확히 표기
  * **자산 성장 곡선 차트 & 권장 저축액 가이드** 완벽 연동
  * 불필요한 초기 설정 모달 및 혼선을 원천 제거하여 간결하고 우아한 핀테크 UX 완성

## 2. 연산 및 데이터 무결성
* **현재 자산 산출 공식**:
  각 사용자의 현재 누적 자산 $A_{current} = \sum (\text{순변동 내역})$
  합산 총자산 $A_{total} = A_{jawon} + A_{yein}$
* **스냅샷 입력 시 자동 연산**:
  입력 시점의 총자산과 직전 누적 자산 간의 차이 $\Delta A$를 경과 개월 수 $N$으로 균등 분할하여 월별 저축 레코드 자동 생성 및 실시간 갱신

## 3. 구현 결과
* 상단 히어로 카드 UI 정돈 (자원/예인 현재 자산 및 합산 자산 3분할 뷰)
* 깃허브 배포 및 실시간 구글 시트 연동 완료
